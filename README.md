# ChronicAI - O Seu Companheiro de Saúde

O **ChronicAI** é uma aplicação Next.js moderna concebida para ajudar seniores a gerir as suas condições de saúde crónicas (como Diabetes, Hipertensão e Colesterol) de forma autónoma e informada.

## Funcionalidades Principais

- **Painel de Controlo (Dashboard):** Resumo visual dos sinais vitais e progresso de atividade física semanal.
- **Assistente de Saúde com IA:** Um chatbot empático que fornece conselhos personalizados baseados no perfil clínico do utilizador e dados estatísticos (INS/DGS).
- **Registo Diário Simples:** Interface intuitiva com botões grandes e menus de seleção para registar pressão arterial, peso e atividade.
- **Questionário de Perfil Abrangente:** Recolha de dados biométricos, hábitos de estilo de vida e detalhes específicos da farmacoterapêutica.
- **Segurança de Emergência:** A IA identifica sintomas de urgência e guia o utilizador para os serviços de emergência (112 ou SNS 24).

## Tecnologias Utilizadas

- **Frontend:** Next.js 15 (App Router), React, Tailwind CSS.
- **UI Components:** ShadCN UI, Lucide Icons.
- **IA/GenAI:** Google Gemini (via Genkit) para aconselhamento de saúde e análise de sintomas.
- **Gestão de Estado:** React Context API para dados de saúde locais.

## Aviso Médico

O ChronicAI fornece apenas informações informativas e conselhos de bem-estar. Não substitui, em circunstância alguma, o diagnóstico ou tratamento por um profissional de saúde qualificado. Em caso de emergência, contacte sempre o 112 ou o SNS 24 (808 24 24 24).
